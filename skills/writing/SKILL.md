# ✍️ Writing Skill — Teknik Yazım Rehberi

## Amaç
Net, yapılandırılmış ve hedef kitleye uygun yazılı içerik üretmek.

## Talimatlar

### 1. Yazım Türünü Belirle
Yazmadan önce sor:
- **Hedef kitle**: Teknik mi? Genel mi? Karar vericiler mi?
- **Tür**: Teknik dok. / Rapor / README / Blog / E-posta / Sunum notu?
- **Uzunluk**: Özet mi (< 500 kelime), orta (500-1500), detaylı (> 1500)?
- **Ton**: Resmi / Yarı resmi / Samimi?

### 2. Yapı Planı (Her Zaman Önce Yap)
```
1. Giriş — Ne anlatılacak, neden önemli?
2. Ana bölümler — Konuya göre 2-5 başlık
3. Sonuç — Özet, eylem çağrısı veya öneri
```

### 3. Teknik Dokümantasyon
- **README formatı**: Kurulum → Kullanım → API referansı → Katkı
- **Kod örnekleri**: Her önemli konsept için çalışan kod
- **Uyarılar**: IMPORTANT/WARNING/TIP gibi vurgular
- **Versiyon bilgisi**: Hangi versiyona ait olduğunu belirt

### 4. Rapor Yazımı
- **Yönetici özeti**: İlk paragrafta tüm anahtar bulgular
- **Veri**: Sayıları bağlama oturt (karşılaştırma, yüzde)
- **Sonuç ve öneri**: Net, uygulanabilir adımlar
- **Ekler**: Teknik detayları ana metinden ayır

### 5. Dil ve Stil Kuralları
- **Aktif cümle** yaz: "Sistem analiz eder" ✓ / "Analiz sistemi tarafından yapılır" ✗
- **Kısa paragraf**: 3-4 cümle maksimum
- **Başlıklar**: Soru veya eylem formu ("Nasıl kurulur?" / "Veritabanını bağla")
- **Jargon**: Hedef kitleye göre aç veya kaldır
- **Tutarlılık**: Bir terimi seç, hep onu kullan

### 6. Gözden Geçirme
- İlk taslağı yaz, sonra kısalt (%20 çıkar)
- "Bu cümle olmasa ne kaybolur?" sorusunu sor
- Başlıklarla iskelet mantıklı mı? Akış var mı?
